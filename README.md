# Exercícios SQL

Repositório criado para reunir exercícios e práticas de **SQL**, com foco no **SQL Server**, visando aprimorar meus conhecimentos em Banco de Dados e servir como material de apoio para a **monitoria da disciplina de Banco de Dados**.

## 🎯 Objetivos

- Aprimorar a prática e a lógica de consultas SQL;
- Consolidar conhecimentos sobre bancos de dados relacionais;
- Praticar comandos e recursos do SQL Server;
- Desenvolver maior autonomia na construção e análise de consultas;
- Revisar conteúdos da disciplina de Banco de Dados;
- Utilizar os exercícios como apoio durante a monitoria.

## 🛠️ Tecnologias

- **SQL**
- **Microsoft SQL Server**
- **SQL Server Management Studio (SSMS)**
